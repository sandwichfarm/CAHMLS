# Plan 24-01: Extract, harden, cover, and document the SDK

## Tasks

1. **Extract the package (SDK-01).** Move coordinator, server, relay, crypto, MLS, and client modules to `packages/sdk/src`, rewrite imports, inject application services, and keep all existing tests passing.
2. **Add the runtime (SDK-03).** Move lifecycle logic to `runtime/coordinator-runtime.ts`; reduce `src/coordinator/coordinator.svelte.ts` to a binding.
3. **Fix defects (SDK-07).** For each defect: failing test first, then the fix.
4. **Cover the SDK (SDK-04).** Add per-module tests, then enforce thresholds in `packages/sdk/vitest.config.ts` and CI.
5. **Verify the package (SDK-02).** `packages/sdk/scripts/verify-package.mjs` loads each entry point and inspects the tarball.
6. **Document (SDK-05).** VitePress guides and TypeDoc reference, built in CI.
7. **Prove no regressions (SDK-06).** `pnpm lint`, `tsc`, `pnpm test`, `pnpm build`, `pnpm test:e2e`, `pnpm check:upstream`, `pnpm test:upstream-interop`, compared against `master`.
